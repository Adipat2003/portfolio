Taking an inspection app from one phone platform to both

Stood up the second mobile platform from scratch: toolchain, builds, deployment to test devices, and the two failures that only appeared on managed corporate devices.

The problem

The app worked in the emulator but failed on corporate-network devices, and a previous user's sign-in session survived sign-out and blocked the next user.

What was owned

Owned the rollout end to end, including build signing, same-day redeploys, and driving the fix with the security and device-management teams.

Approach

  1. Traced certificate failures with the security and network teams to a missing corporate root trust, fixed with a network security configuration
  2. Found and fixed the single sign-on session that outlived sign-out
  3. Same-day bug fixes and redeploys so testers were never blocked

Outcome

The app runs on both platforms on managed devices, with a rollout that never left testers waiting.
