Access control for a 75-endpoint inspection API

Role and facility permissions resolved on every request and enforced by one shared gate at every write path, so users only see and edit what their role and ramps allow.

The problem

Authorization rules were scattered and easy to bypass, with no audit trail of who could reach what.

What was owned

Designed and built the role and facility access model, the shared request gate, the refusal error surface, and the access-assignment audit trail.

Approach

  1. Roles plus facility scoping, resolved per request rather than cached per session
  2. One declarative gate on every portal and write endpoint
  3. Machine-readable refusal errors following a standard problem-details format
  4. Filterable audit trail of access changes

Outcome

Authorization lives in one contract instead of scattered checks, and every access change is attributable.

Figures

  • 75 API paths on the platform (self-reported, source: BAM OpenAPI contract)
  • 214 commits on the backend service (self-reported, source: commit and PR breakdown)
