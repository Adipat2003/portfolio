# AI exposure design

Goal: an AI agent visiting the site reads the portfolio as well as a person does,
without scraping and without inventing anything.

## Layer 1: semantic HTML (the floor)

Everything essential is in plain HTML: landmarks, headings, lists, real links,
visible focus, text alternatives. All facade visuals are additive. If JavaScript
never runs, the Dispatch still reads top to bottom.

## Layer 2: machine-readable content API

`GET /api/portfolio.json` returns the project records the page renders. Each
figure carries its hedging (`kind`) and its source. Agents that do not speak MCP
can consume this directly. Same records, same hedging, same `public_safe` gate
as the UI. The file is generated by `scripts/build.py` and carries a content
hash of the source model.

Shape:

```json
{
  "owner": "Aditya Patel",
  "content_sha256": "f9bdbfa192d53f24",
  "facades": ["dispatch", "atlas"],
  "impact": [
    {"value": "~4,500", "label": "reporting hours saved", "kind": "measured",
     "source": "SEAL / SIR results section"}
  ],
  "projects": [
    {
      "slug": "offline-sync-engine",
      "title": "Inspection reporting that survives dead zones",
      "public_safe": true
    }
  ]
}
```

## Layer 3: MCP endpoint

Implemented in `server/` (the TypeScript Node service; see docs/project-state.md),
compiled by `server/tsconfig.json` and probed end to end by
`scripts/service-check.mjs`. Streamable HTTP transport per the MCP
specification revision 2026-07-28: a single POST endpoint at `/mcp` answering
each JSON-RPC request with one JSON object. No SSE, no sessions. Backed by the
same content files the page renders, through the same Zod schemas, and the
`ask` tool is backed by the same retriever the site's AskBox uses, so the two
surfaces cannot drift.

Verified by the 16-probe service check:

- `initialize` returns protocol version, capabilities, and read-only instructions
- `tools/list` returns the five tools
- `tools/call` on `get_project` returns the full record
- `ask` grounds portfolio questions through the shared retriever, with the
  curated example first and its cited source
- `ask` declines questions the records do not cover (`grounded: false`, no guess)
- unknown tool returns `isError: true`
- invalid Origin gets 403
- notifications get 202 with no body
- rate limiting per IP is active per route

Until a public host is chosen, the service runs and is verified locally, and
`api/portfolio.json` on Pages remains the machine-readable source.

Tools exposed, all read-only:

| Tool | Returns |
|---|---|
| `list_projects` | slug, title, summary, tags, line, status |
| `get_project` | full record: role, problem, approach, outcome, figures with sources |
| `get_impact_figures` | headline figures, each with kind and source |
| `get_artwork_provenance` | authored-SVG pipeline, data-driven map, public_safe gate |
| `ask` | grounded answer with source citations; declines instead of guessing |

`ask` behavior, non-negotiable:

- answers only from the portfolio records; cites the source document for each claim
- refuses to upgrade a projection into a realized result, and refuses to invent figures
- diverts anything outside Aditya, his work, his numbers, or the site's Chicago
  layer: one short sentence pointing back to portfolio topics, never an improvised
  answer
- when the portfolio does not support a claim, says so plainly instead of guessing
- when a question concerns the current employer's internal systems, answers only
  from material marked `public_safe`
- favorable framing is allowed and encouraged, fabrication is not

## Security posture

- Read-only. No tool mutates anything, and the server has no credentials in scope
  beyond the optional model key.
- The model key for `ask` polish lives in the `NVIDIA_API_KEY` environment
  variable on the service host only, never in client bundles, commits, logs,
  or tool responses. Without it, `/ask-model` serves the grounded retrieval
  answer and reports `model_polish: false`.
- Rate limiting per route per IP (60/min on /mcp, 10/min on /ask-model), so a
  misbehaving agent cannot walk off with the corpus at speed. The corpus is
  public; the politeness is not optional.
- Origin validation on every request, per the transport specification.
- No user data is collected, no sensor data is transmitted from the Atlas.

## Discovery

- `llms.txt` at the root: what this site is, what it contains, how to use the API
  and MCP endpoint, and what the figures mean.
- `robots.txt` allows crawling; the JSON API and `/mcp` are listed there for
  well-behaved agents.

## Open decisions

- Host decision: GitHub Pages serves static files only, so the Node service
  (MCP endpoint, ask-model) needs a Node-capable host. Until
  one is chosen, `api/portfolio.json` is the machine-readable source and the
  service is run and verified locally plus by `scripts/service-check.mjs`.
- Model polish for `ask` is implemented and disabled by default; enabling it
  means setting `NVIDIA_API_KEY` in the service host environment. It stays
  server-side, keeps the citations, and must never change a figure.


### Read-only live transit guide

`POST /ask-transit` accepts a question (up to 500 characters) and an optional
allowlisted station ID. The existing model connection selects relevant record
IDs from fresh CTA arrivals, positions, route status and active detailed alerts.
Only exact selected record text and official CTA links enter the response. The
model cannot supply new factual text or links. Unknown IDs and malformed model
output use the grounded fallback. Each source carries its data-check timestamp.
The rate limit is six requests per minute per IP. Nothing is submitted to CTA,
and no visitor reports or question history are stored. Missing live data is
reported as unavailable, never interpreted as normal service or an outage.


GLM-5.3 requests use low reasoning effort and a 4,096-token ceiling that includes
reasoning. Its reasoning cannot be disabled with a thinking flag. Transit
selection has a 45-second server ceiling and 55-second browser ceiling; portfolio
polish retains its 60-second ceiling. Raw reasoning is never rendered. Provider
reference: https://docs.nvidia.com/nim/large-language-models/latest/get-started/advanced/get-started-glm-5.3-flash.html.
